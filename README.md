# Tender Intelligence

Веб-сервис для загрузки и анализа тендерной документации, а также поиска ответов по содержимому документов с указанием источников.

Проект находится на начальном этапе разработки. Инструкции по локальному запуску, настройке провайдеров и демонстрационный сценарий будут добавлены вместе с рабочими компонентами приложения.

## Требования к окружению

- Python 3.12;
- PostgreSQL с расширением pgvector;
- Docker и Docker Compose.

## Проверки качества

После установки зависимостей для разработки доступны команды:

```bash
ruff check .
ruff format --check .
mypy app
pytest
```
